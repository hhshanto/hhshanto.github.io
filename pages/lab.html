EXPERIMENT · NOT PART OF THE SITE

Background lab

Three ways to render depth behind the page, at the same size and with the same words on top of each. Check both themes. The question for all three is the same: does Cormorant at 15px stay readable, and what does it cost.

{%- comment -%} ── 1. WebGL ─────────────────────────────────────────────────────────────── A fullscreen quad and a fragment shader. The canvas takes its palette from the theme tokens at runtime — see the note in lab-shader.js — so this is the only one of the three where colour lives somewhere other than _tokens.scss, and it is worth watching for that reason alone. {%- endcomment -%}

No WebGL context — the panel falls back to the flat page ground.

Cheapest per pixel and the most flexible: anything expressible as a function of position and time. The catch is that the palette has to be handed to it in numbers, so this is a second place colour is defined — it re-reads the tokens on a theme switch rather than keeping its own copy, which is the least bad version of that.

{%- comment -%} ── 2. CSS 3D ────────────────────────────────────────────────────────────── Real perspective, no canvas and no shader: four translucent planes at different Z, rotated by the pointer. Everything here except the pointer listener is CSS, so it composites on the GPU without a frame loop. {%- endcomment -%}
