{%- comment -%} One piece on the constellation map. Only the piece variant lives here. The root, domain and sub-topic nodes are written inline in pages/constellation.html because each occurs once per loop and differs in element and in what it carries — a sub-topic is a span, a domain links to its index, the root is neither. A piece is emitted from two places (under its sub-topic, and under its domain when it has none) with the same nine attributes, and that is what earns an include. Parameters — all required, none defaulted, because a node missing one is a node the simulation silently drops: document the collection document domain its entry from _data/domains.yml parent the data-node id this hangs from excerpt the readout body, already truncated by the caller The escapes are not decoration. A title with a quote in it — and this site has "the 'God Particle'" — closes the attribute early and swallows the rest of the tag. {%- endcomment -%}
