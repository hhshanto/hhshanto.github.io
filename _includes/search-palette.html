{%- comment -%} Screen 1f — the ⌘K palette. Included once, by the default layout, so every page carries it. It ships in the HTML rather than being built by JS on first open: the panel is a dialog with a focus trap, and assembling that at the moment focus needs to move into it is how the first keystroke ends up lost. The whole thing is `hidden` until opened, so it costs a reader nothing. The mock draws a blinking 1.5px accent caret. That is a real input's own caret with `caret-color` set — a decorative element painted next to a hidden field would not follow the text, and a hidden field is what breaks screen readers. {%- endcomment -%}
