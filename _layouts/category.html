--- layout: default --- {%- comment -%} Screen 1d — a domain's front page. The page supplies `collection:` in its front matter; everything else is derived. The title, description and position in the nav come from _data/domains.yml, the same list the masthead reads, so a domain's name cannot say one thing in the header and another in the nav. Density note: 1d is drawn for 14 notes per domain and these hold between one and five. The "Older notes" button at the foot of the list is left out — it would have nothing to load — and the lead piece's figure plate only appears if the document sets `figure:` in its front matter. That is deliberately NOT `image:`: _config.yml gives every page a fallback `image` for link previews, so testing that key would put the site logo on every domain page. {%- endcomment -%} {%- assign domain = site.data.domains | where: 'collection', page.collection | first -%} {%- assign docs = site[page.collection] | sort: 'date' | reverse -%} {%- assign count = docs | size -%} {%- comment -%} Sub-topics are the subdirectory each document sits in — the site has organised its writing that way since long before this redesign.
