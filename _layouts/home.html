--- layout: default --- {%- comment -%} Screen 1a — the masthead home. Three bands: hero, curriculum, recent writing — then the footer from the default layout. Two departures from 1a, both deliberate and both requested after seeing it built. The curriculum sits second, directly under the hero, rather than in a column at the foot: down there it was the last thing anyone reached and every entry wrapped. And the five-domain tile grid is gone — the masthead already carries all five on every page, so the tiles restated the navigation a screen below it. This layout owns the page-level grid and nothing else; every band is an include and every style lives in its own partial. `content` is deliberately unused. index.html carries front matter only — there is no page-specific body, and putting one there would split the home page across two files. {%- endcomment -%}
