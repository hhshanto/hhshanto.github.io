<!--
  This template deliberately has no section headers.

  The previous version supplied Context / Key Points / Analysis / Implications /
  Meta / Updates, and every post that used it came out shaped like a report
  instead of a reflection. Headers that name the machinery of an essay
  ("Introduction", "Key Points", "Conclusion") are the single clearest sign
  that a template wrote the piece rather than a person.

  Instead:

  - Start with the actual thing. No "Introduction" header. The first paragraph
    is the introduction; it doesn't need announcing.
  - Use headers that carry content. "When I Feel Hopeless" tells the reader
    something, "Analysis" doesn't.
  - No em-dashes. Not one. Use a period, a colon, a comma, or parentheses.
  - Let sections be uneven. If one idea needs four paragraphs and another needs
    one sentence, that's the argument showing through. Symmetric sections of
    equal length are a template asserting itself.
  - Prefer paragraphs to bulleted lists of bolded phrases. The connective
    tissue between three points is usually where the thinking is, and the list
    format is what deletes it.
  - End when you're done, not with a resolution. `confidence: low` exists so a
    post is allowed to stay unresolved.

  References go at the bottom under a `## References` heading if you have any.
  Don't add citations you didn't use.

  Run /deaiify on the draft before publishing.
